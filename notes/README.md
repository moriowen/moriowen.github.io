# Notes

Working material behind the resume and the research writeups. None of this is built or served —
Astro publishes only `src/pages/` and `public/`, so these files exist for reference and history.

| file | what it is |
|---|---|
| `research-source-review.md` | Close reading of the five research PDFs in `public/papers/`. Records what each document actually claims, page by page, and flags where two documents disagree or a claim is not reproducible from the text. The publication writeups under `src/content/publications/` are derived from this. |
| `research-section-recommendation.md` | Which papers belong on the one-page resume, how to phrase them, and which existing claims are overstated and need correcting. |
| `resume-review-direction.md` | Direction for the J.P. Morgan Chase experience bullets, plus the platform context needed to keep them accurate and defensible. |

Merged in from a separate `~/dev/resume` folder so the resume and the site that presents it live in
one place.
